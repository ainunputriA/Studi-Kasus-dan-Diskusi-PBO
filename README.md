## Konsep OOP

- **Abstract Class:** Kendaraan menjadi class dasar.
- **Inheritance:** Mobil dan Motor mewarisi class Kendaraan.
- **Polymorphism:** Method tampilkanInfo() dapat menampilkan informasi sesuai jenis kendaraan.
